# Router Principal de Agente — kotlin-agent-rules

Al iniciar cualquier interacción en un proyecto de **Kotlin (Android Nativo / KMP)**, el Agente de IA debe leer las siguientes instrucciones de gobernanza:

1. **Comunicación**: `.agents/core/communication.md`
2. **Motor de Estado**: `.agents/core/brain.md`
3. **Registro de Comandos**: `.agents/core/commands.md`
4. **Estructura del Proyecto**: `.agents/knowledge/kotlin_structure.md`
5. **Estilo de Código**: `.agents/knowledge/code_style.md`
6. **Arquitectura**: `.agents/knowledge/architecture.md`
