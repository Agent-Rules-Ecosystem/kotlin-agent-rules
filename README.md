# 🤖 kotlin-agent-rules

> Repositorio canónico de gobernanza y reglas de agente para **Kotlin (Android Nativo / KMP)**.
> Parte de la organización [Agent-Rules-Ecosystem](https://github.com/Agent-Rules-Ecosystem).

## 📌 Descripción

Gobernanza declarativa Markdown para la gestión de proyectos en **Kotlin**. Define la máquina de estados, mapa de rutas y conocimientos arquitectónicos para asistentes de Inteligencia Artificial (Gemini, Claude, Cursor, OpenAI).

## 📁 Estructura

- `core/`: Protocolo de estado, máquina de estados, comandos e instrucciones de comunicación.
- `adapters/`: Archivos de integración para IDEs y asistentes.
- `knowledge/`: Guías arquitectónicas, estilo de código y ciclo de vida de Kotlin.
- `templates/`: Plantillas de seguimiento (`overview/`).
